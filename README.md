# SQL-Essential-Training
A collection of queries performed on the WSDA_Music.db provided by the SQL Essential Training Course taught by Walter Shields.

## 📁 Overview
This repository contains a series of structured SQL queries performed on the WSDA_Music.db database, as part of the SQL Essential Training course by Walter Shields. The goal was to practice and demonstrate core SQL concepts through real-world-style data exploration and reporting.

## 🧠 Query Functions
- Writing clean, modular SQL queries
- Extracting insights from relational data
- Performing joins, aggregations, and subqueries
- Filtering, sorting, and grouping data
- Creating columns and temporary views
- Cleaning data for analysis
